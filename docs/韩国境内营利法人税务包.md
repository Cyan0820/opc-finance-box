# 韩国境内营利法人税务设计包

`jurisdiction.kr_domestic_corporation` 是韩国境内营利株式会社（Jusik Hoesa）、有限公司（Yuhan Hoesa）和有限责任公司（Yuhan Chaegim Hoesa）的 design 级税务 Pack。它整理法人登记、营业登记、法人税、地方法人所得税、VAT/电子税票和源泉税证据与人工日历，不是申报软件，也不构成韩国税务意见。

## 自动化边界

Pack 可以确定性地校验证据引用、主体声明、规则新鲜度和人工日历必填项，但不会：

- 收集法人登记号、营业登记号、税务编号或 HomeTax/WeTax 用户标识原值；
- 判断韩国税务居民、主体法律形式、法人税/VAT/源泉税纳税义务、税率或税额；
- 判断中间预缴、地方主管机关与跨地区分摊、电子税票义务和具体开具/传输期限；
- 判断中小企业、税收优惠、外国投资、集团纳税、常设机构、转让定价、关税或社会保险；
- 生成申报表、登录 HomeTax/WeTax、提交申报或付款。

所有期限都以 `manual_configuration` 任务存在。韩国国税厅公布的常规期限和 2026 税务日历只是核对依据；节假日、延期、主体适用性和账户显示日期必须由有权人批准。

## 服务

- `tax.kr_domestic_corporation.registration_profile`：整理法律形式、营业登记、法人税、地方法人所得税、VAT、电子税票和源泉税登记证据；
- `tax.kr_domestic_corporation.evidence_checklist`：逐规则检查缺失、重复和未知证据 ID；
- `tax.kr_domestic_corporation.build_calendar`：生成法人税、地方法人所得税、VAT、源泉税和电子税票人工配置任务。

## 演示

```bash
python -m src.cli dispatch examples/boxes/kr_dtc_shopify_stripe_jusik_hoesa.json \
  tax.kr_domestic_corporation.registration_profile \
  --entity-id kr_store --input examples/service_requests/kr_registration_profile.json

python -m src.cli dispatch examples/boxes/kr_dtc_shopify_stripe_jusik_hoesa.json \
  tax.kr_domestic_corporation.build_calendar \
  --entity-id kr_store --input examples/service_requests/kr_tax_calendar.json
```
