# 投放经营分析边界与数据口径

## 产品边界

投放经营页服务的是财务资源配置与经营决策，不替代投手的媒体运营台。

财务 Agent 负责：

- 预算、订单、合同、验收、发票、付款与费用归属。
- 媒体消耗和财务入账口径的勾稽、暂估及跨期检查。
- 按游戏、主体、地区、平台和 cohort 观察收入、贡献、LTV、回收和现金占用。
- 在证据充分时给出追加、维持、回撤或先补数据的判断倾向。
- 把关键假设、模型版本、数据成熟度和复核责任写进证据链。

投手负责：

- 实时出价、素材优化、定向、人群和媒体账户日常运营。
- 媒体侧的实时监控、实验编排和具体投放动作。

## 最小数据闭环

| 数据层 | 关键字段 | 财务用途 |
|---|---|---|
| 媒体消耗 | 日期、媒体、账户、游戏、地区、币种、消耗 | 与订单、发票、付款及暂估勾稽 |
| 获客效果 | 新增、激活、付费人数、归因窗口、自然/付费标识 | 计算 CPA/CPI 并判断数据是否可用于效果结论 |
| cohort 收入 | cohort、平台、地区、留存、累计付费、预测 LTV | 判断回收成熟度、LTV/CPA 与回收周期 |
| 财务执行 | 预算、PR/PO、验收、发票、付款、会计期间 | 识别承诺支出、跨期、未开票及现金影响 |
| 经营基准 | 预算版本、目标门槛、毛利/分成口径、汇率 | 形成可复核的追加/回撤判断 |
| 主体主数据 | `entity_id`、游戏、发行区域、合同相对方 | 保留法律主体归属并支持管理汇总 |

## 判断顺序

1. 先对账：媒体消耗与财务投放费不一致时，不讨论 ROI。
2. 再看证据：只有消耗、没有新增/活跃/收入证据时，不宣称投放有效。
3. 再看成熟度：自然月 cohort 与滚动 30 天不能混用；未成熟窗口不得冒充成熟 LTV。
4. 再做归因：自然量与买量、归因窗口、平台和地区必须可解释。
5. 最后给门控：结合净收入、分成、直接成本、现金承诺和回收周期给出追加/维持/回撤倾向。

## 核心护栏

- 媒体消耗不直接等于财务费用；订单、验收、预提、发票和付款是不同状态。
- 毛流水 ROAS 只能作为经营观察，不得冒充净贡献或会计利润。
- 没有投放消耗，不得声称增长来自买量。
- 消耗上升且指标改善，也只能在归因证据成立时谨慎表述。
- `LTV2` 至 `LTV36` 应保持累计口径；首月口径需明确是自然月 cohort 还是其他定义。
- 管理汇总可换算与抵销，但不删除 `cn_studio`、`sg_publisher` 等原始主体归属。
