# 新西兰有限公司 IR4 / GST 税务设计包

`jurisdiction.nz_limited_company` 面向在 New Zealand Companies Register 注册、并经人工确认税务居民状态的普通有限公司。游戏、电商与独立站 Box 可以复用其主体证据、IRD/IR4/GST 证据清单与候选日历接口；成熟度固定为 `experimental/design`。

## 覆盖与排除

本 Pack 覆盖 Companies Register 主体/annual return 证据、公司 IRD 登记与 IR4 scope 证据、GST 登记监控，以及 IR4、income/provisional tax、GST 和 company annual return 的人工配置任务。

它不收集 company number、NZBN、IRD number 或 GST number 原值；不自行判定新西兰税务居民、look-through company、taxable activity、GST 登记义务/供应分类；不计算公司税率、income tax、provisional tax 或 GST；不覆盖 PAYE、FBT、跨境税，也不生成或提交 IR4/GST return，不付款。

## 为什么日历保持人工配置

- IR4 期限依赖 balance date、tax agent 和 extension of time；
- income/provisional tax 付款依赖 residual income tax、方法、分期和实际账户；
- GST 依赖登记、filing frequency、accounting basis、taxable period、31 March/30 November 特殊期间以及假日；
- company annual return 首次在注册后的下一日历年到期，此后使用 Companies Register 分配的 filing month。

因此当前四类日历任务均不发明候选日期。`ready` 只表示证据或配置检查，不表示税务意见、申报批准或付款授权。
