# 统一结算数据模型

MVP以“结算记录”为最小管理对象，而不是以Excel工作表为对象。

每条记录包含：账期、国内/海外、游戏、平台、渠道、原币、结算币、原币流水、结算币流水、不分成金额、退款/坏账、税费、渠道成本、分成基数、渠道占比、分成比例、结算金额、代扣税、预计实收、状态、异常及证据定位。

核心控制：

1. 不同结算币种不得直接相加。
2. 同一工作表存在多个汇总层级时，只选择一个不重复的数据区。
3. 结算金额校验优先使用“渠道后实收 × 分成比例”；无渠道后实收时使用“分成基数 × 分成比例”。
4. 预计实收校验为“结算金额－代扣税”。
5. 原始文件不复制到项目，不读取合同中的银行账户进入前端，不处理用户级明细。
6. 未通过勾稽的数据进入待确认或异常，不自动确认为收入。

## 导入适配层

不同公司的工作簿先经过“语义适配”，再进入统一结算记录：

1. 发现工作表、候选表头和数据区，优先推荐结算汇总而不是用户级交易明细。
2. 把原表列映射到账期、游戏、平台、渠道、流水、退款、分成基数、分成比例、结算金额、代扣税和预计实收等标准字段。
3. 为表内缺少的维度配置缺省值，例如游戏、平台、渠道、币种和业务范围。
4. 明确结算金额来自表内声明值，或使用“分成基数 × 分成比例 / 渠道后净额 × 分成比例”计算。
5. 将以上配置连同表头指纹保存为本地模板；下次表头一致时自动推荐，仍允许人工复核和调整。

导入模板不包含对账单金额、交易明细、银行账号等业务数据。
