# 税务申报辅助包

智能财务工作台把税务交付拆成四层，避免把“导出 Excel”误认为“已经报税”：

1. **工作底稿**：从台账生成候选金额、勾稽结果、缺口与判断倾向。
2. **表单契约**：按主体、所属期、地区和适用身份锁定官方表单版本，并把内部字段映射到官方栏次。
3. **复核与释放**：有权人同意时保存主体、期间、表单契约和数据指纹；任何候选值变化都会使旧复核失效。
4. **申报与回执**：人工进入电子税务局申报；“申报成功”和“已缴款”必须回写流水号及回执/缴款证据。

## 当前可以交付

- 增值税及附加、A200000 企业所得税预缴、A01103 印花税税源、个税扣缴和财务报表工作底稿。
- ZIP 申报辅助包：工作底稿、表单契约、字段映射、阻塞项、数据指纹和回执登记模板。
- 上海 2026 年增值税试点身份门控：只有确认收到主管税务机关试点通知后，才使用试行表契约。
- 主体隔离：`cn_studio` 和 `sg_publisher` 的法定税务记录不可合并审批或申报。

## 当前不能声称

- ZIP 或 XLSX **不是电子税务局可直接上传文件**。
- 未取得属地导入规范、申报接口授权和真实回执前，`direct_upload_ready` 固定为 `0`。
- 工作台可给出判断倾向和不同选择的影响，但法定申报仍由有权申报人操作和确认。
