# 英国 Private Limited Company 税务设计包

`jurisdiction.uk_limited_company` 为英国 private company limited by shares 提供版本化、官方来源支撑的税务运营设计边界。它适合英国主体的游戏、电商或独立站 Box，但目前仍是 `experimental / design`：输出是登记证据、复核任务和候选日历，不是税务意见、税额或可提交申报表。

## 当前覆盖

- Companies House 主体类型、法定名称与 accounting reference date 证据；
- active/trading 与 Corporation Tax 服务登记证据；
- CT600/Company Tax Return 候选日历；
- Corporation Tax 付款安排的人工配置任务；
- VAT 滚动 taxable turnover、未来 30 天预测及登记复核证据；
- VAT return 与付款期限的人工配置任务；
- private company 年度账目的 Companies House 候选日历；
- CT600、财务报表、税务计算、iXBRL、授权声明和回执证据清单。

Pack 不收集 UTR、company number 或 VAT number 原值。只允许保存证据系统中的引用和抓取时间，以降低税务标识符进入请求、日志和交付包的风险。

## 明确不覆盖

当前不计算 Corporation Tax 或 VAT，不判断 VAT 供应地/税率、Northern Ireland/EU 特殊交易或登记义务，也不覆盖 PAYE、海关、个人税、集团/大公司分期付款、转让定价、全球最低税和任何外部提交。

Corporation Tax 付款日期、VAT return 日期和支付清算要求保持 `manual_configuration`。即使 CT600 或 Companies House 生成了日期，也只是按已确认财年结束日形成的候选；首次账目、notice to deliver、会计期间变化、延期、银行假日和大公司规则都必须由英国税务/公司秘书复核人确认。

## 同一独立站栈的英国样板

```bash
python -m src.cli create examples/box_specs/shopify_stripe_uk_ltd.json \
  --output outputs/shopify-uk.json
python -m src.cli compile outputs/shopify-uk.json \
  --output outputs/shopify-uk-build
python -m src.cli doctor outputs/shopify-uk.json
```

严格配置样板位于 `examples/boxes/uk_dtc_shopify_stripe_ltd.json`。它与 CN、SG、US 和 HK 样板复用 Commerce、DTC、Shopify、Stripe 及订单到银行到账证据链，只替换法律主体、GBP、UK GAAP 和 UK Ltd Tax Pack。
