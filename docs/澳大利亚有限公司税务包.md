# 澳大利亚 Proprietary Limited Company 税务设计包

`jurisdiction.au_proprietary_company` 面向在澳大利亚注册的 proprietary company（常见名称后缀为 Pty Ltd）。它为游戏发行、电商和独立站 Box 提供相同的主体登记、官方来源、证据清单与候选日历接口；当前成熟度固定为 `experimental/design`。

## 范围

当前 Pack 覆盖：

- ASIC proprietary company 类型与 annual review 证据；
- ABN entitlement/登记回执、公司 TFN、GST 和 PAYG withholding 登记证据；
- Company tax return 与付款日的人工配置任务；
- BAS 周期、statement 日期与付款日的人工配置任务；
- 基于显式 ASIC annual review date 的两个月候选日期；
- 逐规则证据清单、180 天来源复核新鲜度和人工 review gate。

当前 Pack 明确排除：

- 公司税率、base rate entity 或任何优惠资格判断；
- GST turnover、供应是否 connected with Australia、taxable/GST-free/input-taxed 分类；
- 公司税、GST、PAYG、FBT、super 或其他金额计算；
- 州/领地 payroll tax、worker compensation、跨境税、转让定价、合并集团和 substituted accounting period 判断；
- 可提交 company tax return、BAS 或 ASIC 表单；
- 税务登记、申报、付款和任何外部提交。

## 官方来源

规则于 2026-08-13 核验，主要依据：

- [Australian Business Register — Applying for an ABN](https://www.abr.gov.au/business-super-funds-charities/applying-abn)
- [Australian Government — Tax registration for your business](https://business.gov.au/registrations/register-for-taxes/tax-registration-for-your-business)
- [ATO — Registering for GST](https://www.ato.gov.au/businesses-and-organisations/gst-excise-and-indirect-taxes/gst/registering-for-gst)
- [ATO — How to lodge your company tax return and pay](https://www.ato.gov.au/api/public/content/0-e220713e-6a6f-4401-b966-8bddf3ba96fd)
- [ATO — Companies and super funds lodgment program](https://www.ato.gov.au/api/public/content/0-07e0b405-bd64-4e3b-856b-20d7be074f13)
- [ATO — Due dates for lodging and paying your BAS](https://www.ato.gov.au/businesses-and-organisations/preparing-lodging-and-paying/business-activity-statements-bas/due-dates-for-lodging-and-paying-your-bas)
- [ASIC — Company annual review](https://www.asic.gov.au/for-business-and-companies/companies/company-annual-review)

ATO 的 company tax return 日期会随主体类别、申报渠道、历史状态、registered agent lodgment program、ATO deferral 和 SAP 改变。BAS 日期也受实际 reporting cycle、在线/代理申报优惠、statement、延期及公共假日影响。因此这两类日期使用 `manual_configuration`，系统不会从财年结束日或一般描述发明截止日。

ASIC annual review fee 和 solvency resolution 通常围绕实际 annual review date 的两个月期限。服务只有在请求中显式提供 `asic_annual_review_date` 时才生成候选日期；缺少该日期时输出 `needs_configuration`。

## Box 样板

严格配置：

```bash
python -m src.cli validate \
  examples/boxes/au_dtc_shopify_stripe_pty_ltd.json
```

从简化规格创建：

```bash
python -m src.cli create \
  examples/box_specs/shopify_stripe_au_pty_ltd.json \
  --output outputs/shopify-au.json
```

这两个样板使用 `AUD`、`AASB` 和 `06-30` 作为可编辑起点。它们不是对任何真实公司的准则、财年或登记结论。

## 服务

Pack 提供三个确定性服务：

- `tax.au_proprietary_company.registration_profile`
- `tax.au_proprietary_company.evidence_checklist`
- `tax.au_proprietary_company.build_calendar`

登记画像只接受证据引用对象：

```bash
python -m src.cli dispatch \
  examples/boxes/au_dtc_shopify_stripe_pty_ltd.json \
  examples/service_requests/au_registration_profile.json
```

传入 `acn`、`abn`、`tfn`、`tax_id` 等原值会失败关闭。即使 ABN、TFN 或 GST 状态声明为 `confirmed`，没有证据引用也只会得到 `needs_evidence`。

候选日历：

```bash
python -m src.cli dispatch \
  examples/boxes/au_dtc_shopify_stripe_pty_ltd.json \
  examples/service_requests/au_tax_calendar.json
```

示例显式传入虚构的 `asic_annual_review_date`，只为演示确定性候选算法。输出仍固定保留：

```json
{
  "candidate_only": true,
  "company_tax_rate_determined": false,
  "tax_calculation_performed": false,
  "filing_performed": false,
  "payment_performed": false,
  "external_submission_enabled": false
}
```

## 上线前必须完成

- 用真实 ASIC extract、annual statement、ATO 注册回执和账户日期替换演示引用；
- 由澳大利亚注册 tax agent/BAS agent 或有权专业人士确认主体范围、GST/PAYG/FBT/super 与州税适用性；
- 在每个期间按实际 ATO/ASIC 资料配置日期，不复用示例 anchor；
- 保存批准人、规则版本、证据引用、实际提交回执与付款回执；
- 在代表性 shadow run 和专业签认完成前，不提升 `design` 成熟度。
