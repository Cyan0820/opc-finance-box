# 逐主体月结与外部会计复核包

集团视图用来看项目经营，法定动作不能在集团口径执行。工作台对以下操作强制要求单一 `entity_id`：

- 凭证复核、过账、关账、重开和下期结转；
- 收入会计政策、资产卡片、费用暂估和税务复核；
- 税务工作底稿、申报辅助包与外部会计复核包。

期间状态存储在 `periods/<entity_id>/<YYYY-MM>.json`，因此即使两个主体使用相同账期和相同凭证草稿 ID，也不会互相接受、过账或关账。旧的无主体期间文件仅作为兼容读取，新法定动作不回写到其中。

`GET /api/accountant-pack?entity_id=<id>&period=<YYYY-MM>` 产生单主体 ZIP。核心交付物包括：

- `00_交付清单.json`：主体、地区、本位币、准则、期间、关账门和内容指纹；
- `03_凭证草稿.csv`、`11_已过账试算平衡.json`、`12_已过账财务报表.json`；
- `13_银行余额调节.json`、`14_税务申报工作区.json`；
- 限于当前主体和期间的数据集清单与审计日志。

包内文件用于复核，不代表已记账、已申报或已获得付款授权。CN 主体可在已实现的 `filing_assist` 边界下产生中国申报辅助资料；SG 主体当前为 design 级，只生成登记事实、证据清单和候选日历，不生成中国税表或声称可直接提交。
