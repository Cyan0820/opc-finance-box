# 添加纳税地区 Pack

## 产品边界

OPC Finance Box 的“选择纳税国家”是选择一个已安装、版本化且有官方来源的 jurisdiction Pack，不是让通用模型根据国家代码即兴生成税务结论。

当前内置：

- 中国大陆：`jurisdiction.cn_mainland`，工作底稿级。
- 新加坡：`jurisdiction.sg`，设计级。
- 美国联邦 C corporation：`jurisdiction.us_federal`，设计级；不含州及地方税。
- 香港法团利得税：`jurisdiction.hk`，设计级。
- 英国 Private Limited Company：`jurisdiction.uk_limited_company`，设计级；不含 PAYE、海关、个人税和外部提交。

未安装地区包时，系统仍可做通用记账、对账、现金和经营分析，但必须拒绝该主体的税务日历、税额和申报能力。

## 创建初始 Pack

```bash
python3 -m src.cli jurisdiction-init \
  --output-root extensions/jurisdictions \
  --slug us_federal \
  --country-code US \
  --display-name "US Federal Tax Design Pack" \
  --source-authority "Internal Revenue Service" \
  --source-title "Official business tax guide" \
  --source-url "https://www.irs.gov/businesses" \
  --verified-at 2026-08-13 \
  --rules-effective-at 2026-01-01
```

脚手架强制输入一个 HTTPS 官方来源，并只生成 `experimental` / `design` / `evidence` 级 Pack。它不会生成税率、截止日或可提交表单。

## 从 design 升级

1. 定义主体登记事实、适用条件和必需证据。
2. 为每条规则保留主管机关、原文地址、生效日、核验日和来源 ID。
3. 把截止日表达为结构化 schedule；无法统一的属地期限使用 `manual_configuration`。
4. 金额、税率、期间和舍入用确定性代码，LLM 只负责材料理解和解释。
5. 给每条自动化建立正常、边界、缺资料、规则过期和不适用测试。
6. 配置当地专业复核人、替补人和外部提交权限。
7. 只有达到明确验收标准后才升级成熟度；`filing_assist` 仍不等于无人值守申报。

## 安装与选择

完成审核后将 Pack 放入 `packs/jurisdictions/<slug>/`，运行：

```bash
python3 -m src.cli options
python3 -m src.cli validate examples/boxes/your-box.json
python3 -m unittest discover -s tests -q
```

`create_box.py` 会自动从已安装 Pack 枚举国家。若同一国家存在联邦、州、省或特殊登记范围，应在严格 Box 配置中显式选择具体 `tax_pack`，不应只靠二位国家代码推断。
