# 加拿大联邦公司 T2 / GST-HST 税务设计包

`jurisdiction.ca_federal_corporation` 面向依据 Canada Business Corporations Act 注册、并经人工确认属于加拿大税务居民的公司。它让游戏、电商与独立站 Box 复用同一套主体登记证据、官方来源、T2/GST-HST 证据清单及候选日历接口；成熟度固定为 `experimental/design`。

## 明确范围

本 Pack 只覆盖：

- Corporations Canada 的联邦公司主体状态与 annual return 证据；
- CRA Business Number、corporation income tax program account 和 T2 filing scope 的证据引用；
- GST/HST 登记与 reporting period 的复核提示；
- 财年结束后六个月的 T2 申报候选日；
- 公司税 balance due、GST/HST return/payment 和联邦 annual return 的人工配置任务。

它明确不做：

- 不收集 corporation number、BN、program account 或 GST/HST number 原值；
- 不根据 Box 配置判定加拿大税务居民、CCPC、小企业扣除或关联公司状态；
- 不根据收入/收货地址自动判定 GST/HST small supplier、供应分类、登记义务或适用税率；
- 不计算联邦/省区公司税、GST/HST、分期付款或税收抵免；
- 不覆盖 Alberta/Quebec 等省区公司所得税申报、QST/PST/RST、工资税、跨境税或 SR&ED；
- 不生成 T2、GST/HST return 或可提交文件，也不申报、付款或写入外部系统。

`federal_corporation` 只表示调用方声明的主体类型。只有同时附上 Corporations Canada 状态证据和独立的加拿大税务居民复核证据，登记 profile 才能通过这两个证据门；系统仍把两个法律/税务结论标记为人工确认。

## 日历边界

CRA 官方指引要求 corporation income tax return 在每个 tax year 结束后六个月内申报。确定性日历会保留月末语义，例如 `2026-12-31` 生成 `2027-06-30` 候选日，但不会自动应用周末或 CRA 认可公共假日的顺延。

公司税余额通常在 tax year 结束后两个月到期；只有在 CCPC、小企业扣除、前期 taxable income/business limit 及关联公司等条件满足时，相关税种可能使用三个月期限。Pack 不会从标签推导这些条件，所以 balance due 只生成需人工配置的任务。

GST/HST 的登记判断涉及单季与连续四个日历季度、供应分类和加拿大连接事实；申报/付款日期还依赖 reporting period 和实际 CRA 账户，因此保持人工配置。

联邦 active corporation 的 annual return 与 ISC information 应在真实 anniversary date 后 60 天内办理。Pack 只有在请求中显式提供 `federal_corporation_anniversary_date` 时，才用 `days_after_date` 生成候选日；缺少锚点会失败关闭，候选日仍需结合 active 状态、当期 register 记录和有权人复核。

## 可调用服务

- `tax.ca_federal_corporation.registration_profile`
- `tax.ca_federal_corporation.evidence_checklist`
- `tax.ca_federal_corporation.build_calendar`

示例：

```bash
python -m src.cli dispatch \
  examples/boxes/ca_dtc_shopify_stripe_federal_corporation.json \
  examples/service_requests/ca_registration_profile.json

python -m src.cli dispatch \
  examples/boxes/ca_dtc_shopify_stripe_federal_corporation.json \
  examples/service_requests/ca_tax_calendar.json
```

输出中的日期全部是候选日期，`ready` 也只说明证据/配置检查通过，不代表专业意见、申报批准、付款授权或外部回执。
