# 爱尔兰 LTD 公司 CT1 / VAT 税务设计包

`jurisdiction.ie_private_limited_company` 精确面向爱尔兰 Companies Act 2014 Part 2 下的 Private Company Limited by Shares（LTD）。它提供 CRO 主体、Revenue tax registration、Corporation Tax/CT1、VAT 与 annual return 的证据和候选日历接口，成熟度固定为 `experimental/design`。

## 安全边界

Pack 不收集 company number、tax reference 或 VAT number 原值；不自行判定爱尔兰税务居民、VAT threshold/供应分类、Corporation Tax 税率或 preliminary tax；不覆盖 DAC/CLG/PLC、EU OSS/IOSS/SME scheme、PAYE/PRSI、RCT、跨境税；不生成 CT1、iXBRL、VAT3 或可提交文件，也不申报或付款。

CT1 期限会受到 accounting period end 在月内的位置、9 个月规则、强制电子申报/豁免和 ROS 日期影响，CT payment 还依赖公司规模和 preliminary tax。VAT3 则依赖实际 VAT 登记、taxable period frequency、ROS/非 ROS 与 RTD。因此这三类任务保持人工配置。

CRO annual return 应在公司实际 Annual Return Date（ARD）后 56 天内提交。只有请求显式提供 `cro_annual_return_date` 时，确定性日历才生成候选；例如 `2026-09-30` 产生 `2026-11-25`。缺少锚点会失败关闭，first return、ARD 变更与财务报表要求仍需人工复核。
