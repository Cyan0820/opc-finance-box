# 日本株式会社 / 合同会社税务设计包

`jurisdiction.jp_domestic_corporation` 是日本内国株式会社（Kabushiki Kaisha，KK）和合同会社（Godo Kaisha，GK）的 design 级税务 Pack。它整理商业登记、法人税、地方税、消费税/适格请求书和源泉所得税证据与人工日历，不是申报软件，也不构成日本税务意见。

## 精确范围

当前 Pack 只覆盖已由证据确认的日本内国 KK 或 GK。分支、外国法人、合名会社、合资会社、个人事业者和其他法人类型不在同一合同内。地方税还必须按实际都道府县、市区町村和办公地点复核。

官方来源截至 2026-08-16 核对：

- 日本法务省的 [Commercial and Corporation Registration](https://www.moj.go.jp/EN/MINJI/houjintouki.html)；
- 国税厅的 [法人番号公表网站](https://www.houjin-bangou.nta.go.jp/en/index.html)；
- 国税厅的 [法人税、地方法人税及防卫特别法人税申报手续](https://www.nta.go.jp/taxes/tetsuzuki/shinsei/annai/hojin/shinkoku/01.htm)；
- 国税厅的 [法人设立时的税务手续](https://www.nta.go.jp/publication/pamph/koho/kurashi/html/07_3.htm)；
- 国税厅的 [Consumption Tax - Basic knowledge](https://www.nta.go.jp/english/taxes/consumption_tax/01.htm) 与 [法人消费税申报期限](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6610.htm)；
- 国税厅的 [适格请求书（Invoice）制度](https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/invoice_about.htm)；
- 国税厅的 [新源泉扣缴义务人指南](https://www.nta.go.jp/users/gensen/shinki/index.htm)；
- e-Tax 的 [法人设立及异动手续](https://www.e-tax.nta.go.jp/e-taxsoftweb/e-taxsoftweb_hojin.htm)，其中明确地方税表单经 eLTAX 提交且结果应在 PCdesk 核对。

## 可执行服务

- `tax.jp_domestic_corporation.registration_profile`：整理 KK/GK、法人税、地方税、消费税、适格请求书与源泉税登记证据；
- `tax.jp_domestic_corporation.evidence_checklist`：逐规则检查缺失、重复和未知证据 ID；
- `tax.jp_domestic_corporation.build_calendar`：生成法人税、地方税、消费税和源泉税人工配置任务。

例如：

```bash
python -m src.cli dispatch examples/boxes/jp_dtc_shopify_stripe_kk.json \
  examples/service_requests/jp_registration_profile.json

python -m src.cli dispatch examples/boxes/jp_dtc_shopify_stripe_kk.json \
  examples/service_requests/jp_tax_calendar.json
```

## 为什么日期保持人工配置

法人税、地方法人税与法人消费税通常以事业年度或课税期间结束后两个月为基础，但延期、中间申报、课税期间缩短、休假日和账户状态都会改变实际期限。地方税还取决于都道府县、市区町村与办公地点；源泉所得税取决于实际付款、收入类型和是否取得纳期特例批准。因此 Pack 不把“两个月”或“次月十日”包装成主体的确定期限。缺少事实时 `candidate_due_date` 为 `null`，并返回 `missing_configuration`。

## 安全边界

Pack 不接收法人番号、税务编号、适格请求书发行事业者登记番号、e-Tax 利用者识别番号或 eLTAX 用户 ID 原值，只接收不含敏感值的证据引用。它不判断税务居民、税率税额、蓝色申报资格、集团通算、消费税课税身份、简易课税、供应分类、源泉扣缴适用性、跨境税、常设机构、转让定价、关税或社会保险，不生成可提交文件，也不申报、付款或访问外部系统。所有输出保留 `tax_advisor_review` 与 `tax_filing_release` 人工 gate。
