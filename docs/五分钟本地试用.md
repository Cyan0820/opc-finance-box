# 五分钟本地试用

`trial-init` 把产品选择、可复验 Box 和本地运行数据目录组装成一个完整试用入口。它适合先体验游戏、独立站或平台电商 OPC Box，不需要先理解 Handoff、运行数据布局或服务环境变量。

## 创建

目标必须是尚不存在的绝对目录。行业使用 `game`、`dtc` 或 `marketplace`；国家使用当前安装 Tax Pack 的两位代码；integration 必须在对应 Profile 白名单内。

```bash
opc-finance-box trial-init /absolute/new/my-opc-trial \
  --profile dtc \
  --country NL \
  --integration shopify_stripe \
  --name "My DTC OPC Trial" \
  --actor founder

opc-finance-box trial-verify /absolute/new/my-opc-trial
opc-finance-box trial-onboarding /absolute/new/my-opc-trial
opc-finance-box trial-run /absolute/new/my-opc-trial
```

启动后访问 `http://127.0.0.1:8765`，按 `Ctrl-C` 停止。端口占用时可使用 `--port 8877`。

## 先看下一步，不先读完整控制手册

`trial-onboarding` 不修改试用目录。它先联合重验 Box 和运行数据，再读取 Handoff 根目录中已经逐字节验证的正式 `setup-checklist.json`，将完整控制压成五段创始人旅程：

1. 运行本地演示 Box：当前可执行。
2. 建立自己的可编辑 Box：沿用本次 `profile / country / integration` 生成 live 候选，不改写 demo。
3. 确认主体、税务、数据源和控制人：默认阻塞，直到真实证据由原验证器接受。
4. 初始化首客私有激活工作区：保持锁定，不把资料放进试用目录。
5. 真实只读并行验证与连续月结：保持锁定，由 Activation 的权威门禁逐步开放。

输出同时给出 setup task 总数、blocking/required/advisory 数量、各阶段责任角色和只含环境变量名称的 Connector 准备要求。`priority_setup_tasks` 只突出阻止外部申报、税务适用性或网络暴露的首批任务；它不声称其他任务不重要。

命令模板使用 `/absolute/...`、`YYYY-MM` 和稳定角色占位符，不返回真实目录、初始化人员、凭证或财务金额，也不会执行命令。`demo_ready=true` 只表示可本机体验；同一输出固定保持 `production_ready=false`、`setup_evidence_recorded=false` 和 `production_readiness_inferred=false`。

通过 `trial-run` 启动后，服务端会用 `OPC_FINANCE_TRIAL_ROOT` 绑定刚刚重验的试用根；浏览器“财务任务流 → 数据连接器准备”顶部会显示同一五段旅程。`GET /api/box/trial-onboarding` 不接受请求路径覆盖。普通源码运行、生产服务或未设置该服务端环境的实例返回 `available=false`，页面自动隐藏试用卡片，不会靠当前 Box 的 `data_mode` 猜测来源。

## 目录边界

```text
my-opc-trial/
├── START-HERE.md
├── trial-workspace.json
├── box/                 # 可复验、不可混入运行数据的 Handoff 工作区
└── runtime-data/        # 可变、版本化、可备份恢复的本地运行数据
```

初始化器始终生成 `demo` Box。`box/` 继续通过原 Handoff verifier 逐成员重建，`runtime-data/` 继续通过版本化存储合同检查；启动器每次先同时重验两者，再把真实路径放入子进程环境。工作台的输出和运行台账不会写进 `box/`，因此试用之后仍能检查 Box 是否被修改。

根目录与子目录使用 `0700`，控制文件使用 `0600`；已有目标、符号链接、额外根成员、manifest/指南改动、Box 改动、运行数据版本不兼容或权限放宽都会失败关闭。初始化中断时保留不完整目录供检查，不自动删除或覆盖；应换一个新目标重试。

## 网络与权限

默认只监听本机回环地址并使用本地匿名模式，不自动打开浏览器。非回环监听必须通过环境变量配置至少 32 字符的 `OPC_FINANCE_API_TOKEN`，或向 `trial-run --auth-file /absolute/private-policy.json` 传入角色策略；同时仍需自行提供 TLS、反向代理和网络访问控制。

试用初始化和验证不会读取 Connector 凭证、访问外部网络或加入真实财务值。选择 Shopify、Stripe、Amazon Seller 等 integration 只会把对应 Pack、Pipeline、配置要求和安全边界装进 Box，不代表真实账户已连接。

## 从试用进入首客接入

试用满意后，不要把 demo 状态解释为生产证据。先执行 `trial-onboarding` 取得与本次选择一致的 `starter-init --data-mode live` 模板，在独立目录建立自己的 Box 并完成 `validate / compile / doctor`；再以新 Box 的 `box.json` 为起点，在另一个新的私有目录执行 `activation-init`，逐主体完成税务适用性、Connector 配置与真实 Shadow、资料交接、首次月结、连续月份和 Stable candidate 独立复核。

`trial-workspace.json` 是本地完整性合同，不是数字签名、财务证据或税务结论。试用模式不授权过账、付款、库存修改、报税或其他外部动作。
