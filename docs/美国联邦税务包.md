# 美国联邦 C Corporation 税务设计包

`jurisdiction.us_federal` 是一个 `experimental/design` 纳税地区 Pack。它只覆盖美国联邦、境内 C corporation 的分类/EIN 证据、2025 tax-year Form 1120 候选日历配置和 corporate estimated tax 证据清单。

它明确不覆盖：

- 州及地方所得税、franchise tax、sales/use tax 与 nexus 判断；
- payroll、employment、excise 或其他专项税；
- S corporation、partnership、未确认联邦税务分类的 LLC；
- foreign information returns、CAMT 或其他专项 schedules 的适用性判断；
- 税额计算、可提交表单、EFTPS 付款、电子申报或外部提交。

## 官方来源与版本

当前 Pack 在 2026-08-13 核验以下 IRS 来源：

- [Instructions for Form 1120 (2025)](https://www.irs.gov/instructions/i1120)：2025 tax-year Form 1120 说明、一般截止日、6 月 30 日财年例外及周末/法定假日规则。
- [About Publication 542, Corporations](https://www.irs.gov/forms-pubs/about-publication-542)：普通境内 corporation 的一般联邦税务与 estimated tax 入口；当前索引所指底层 publication 修订于 2024 年 1 月。
- [Employer identification number](https://www.irs.gov/businesses/employer-identification-number)：EIN 登记与确认证据入口。
- [Topic no. 407, Business income](https://www.irs.gov/taxtopics/tc407)：C corporation、S corporation、partnership 与 LLC 联邦税务分类边界。

来源超过 180 天未复核时，registration profile 与 evidence checklist 返回 `source_review_expired` 并阻断 ready。这个 180 天是产品的来源治理控制，不是 IRS 规定的申报期限。

## 生成美国独立站 Box

与 CN/SG 使用完全相同的 Shopify + Stripe 集成预设，只替换主体的 `tax_country`、本位币和会计准则：

```bash
python -m src.cli create examples/box_specs/shopify_stripe_us_c_corp.json \
  --output outputs/shopify-us.json
python -m src.cli compile outputs/shopify-us.json \
  --output outputs/shopify-us-build
```

生成的严格 Box 选择 `jurisdiction.us_federal`，并启用：

- `tax.us_federal.registration_profile`
- `tax.us_federal.evidence_checklist`
- `tax.us_federal.build_calendar`

税务 Pack 的 `design` 成熟度与 Shopify/Stripe Pipeline 是否可执行是两条独立状态。Connector 和订单到银行证据链可以执行，不代表美国联邦、州或销售税已达到申报级。

## 分类与 EIN 证据

运行虚构、已脱敏的 profile 示例：

```bash
python -m src.cli dispatch examples/boxes/us_dtc_shopify_stripe_c_corp.json \
  examples/service_requests/us_federal_registration_profile.json
```

请求只提交 `source_reference` 与 `captured_at`，不提交原始 EIN。服务会拒绝 `ein`、`ein_number` 或 `tax_id` 字段。即使分类和 EIN 证据齐全，输出仍保持：

- `classification_determination_performed=false`
- `tax_calculation_performed=false`
- `filing_performed=false`
- `external_submission_enabled=false`

S corporation、partnership 或 disregarded entity 会返回 `outside_pack_scope`，不会被悄悄当作 Form 1120 C corporation。

## 候选日历

```bash
python -m src.cli dispatch examples/boxes/us_dtc_shopify_stripe_c_corp.json \
  examples/service_requests/us_federal_tax_calendar.json
```

当前日历故意输出 `needs_configuration`，不生成日期。原因是 Form 1120 有 6 月 30 日财年例外，具体税年说明会更新，且周末/联邦假日需要调整；estimated tax 还取决于适用性、税年、当年计算支持和支付证据。需要当地专业人士显式提供并批准：

- Form 1120 filer 与 tax year end；
- 对应 tax year 的 Form instructions；
- 6 月 30 日财年例外和周末/假日复核；
- approved candidate due date；
- estimated tax applicability、计算支持、分期日历和 EFTPS 证据。

只有这些事实齐全后，未来版本才应考虑加入更具体的确定性日期或 workpaper。测试通过本身不能把 Pack 从 `design` 升级为 `workpaper` 或 `filing_assist`。
